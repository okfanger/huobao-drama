# 模型交互过程与 Codex 文字服务

剧集页的「任务」打开任务中心，默认显示模型交互过程。文字、图片、视频操作共享记录格式；选择「历史生成任务」仍可查看旧任务。旧任务没有过程记录时明确显示「无过程记录」。

## 查看过程

按类型和状态筛选运行记录，点击「查看过程」查看步骤摘要、时间与耗时。展开步骤查看完整提示词、多轮消息、最终请求参数、模型输出、工具参数与返回结果。下载完成后展示图片或视频预览。重复轮询在默认视图合并，展开仍保留每次请求和响应。

运行中实时更新；向上滚动暂停自动跟随，点击「跟随最新」恢复。关闭详情只关闭订阅，后台生成继续。记录存入 SQLite，刷新、切换剧集和重启后可以回看。重启时运行中的记录标记为已中断。每日清理结束超过 30 天的记录；主动清理只删除当前剧集已结束的记录及其事件，不删除生成素材。

文本和工具数据完整保存，凭据脱敏；二进制与 Base64 替换为素材引用或大小、类型等元数据。服务商未暴露的信息显示「未提供」，不记录或推测隐藏思考过程。用量保留实际数字。文本增量合并写入，通常每 100 毫秒刷新，步骤切换和结束前刷新剩余内容。

## Codex 配置

在设置中新增「文字」服务，选择 Codex。API Key、Base URL、温度不适用，因此隐藏。默认模型为「本机默认」，也可以填写本机账户可用的模型名；不支持的模型明确报错，不自动切换模型。

需要在运行后端的同一台机器安装 Codex CLI，并已使用 ChatGPT 登录。此版本不捆绑 CLI、不提供登录流程。CLI 查找顺序为 `HUOBAO_CODEX_BIN`、PATH、常见安装路径；Windows 会寻找 npm 安装的原生可执行文件。连接检查报告安装版本及 ChatGPT 登录状态。服务器、容器环境不能直接复用另一台电脑的登录。

后端使用官方 `@openai/codex-sdk`，精确锁定 `0.160.1`，通过 `runStreamed()` 转换公开事件。每次执行使用独立临时工作目录、只读沙箱和禁用的 shell/web 功能。内部 MCP 服务仅监听 `127.0.0.1` 的随机端口，使用一次运行的临时 Bearer 授权，工具上下文绑定项目和剧集，只提供当前 Agent 的业务工具，运行结束后关闭。不修改全局 MCP 配置。单次运行最多 10 分钟，业务工具调用次数沿用调用方 `maxSteps`；重复 MCP 请求 ID 不重复执行写入，失败后不自动重试。

本期仅支持 Codex 文字服务。图片、视频仍通过已有服务商生成，并共享过程记录。

官方参考：[Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)、[MCP](https://learn.chatgpt.com/docs/extend/mcp)、[配置说明](https://learn.chatgpt.com/docs/config-file/config-reference)。

## 接口

接口位于 `/api/v1`，响应沿用现有 `{ code, data }` 格式。

| 接口 | 用途 |
| --- | --- |
| `GET /ai-runs?episode_id=1&service_type=text&status=completed&limit=50&cursor=...` | 根操作列表，含模型摘要和 `event_cursor`，不含事件正文；支持 `drama_id`、`task_id` |
| `GET /ai-runs/:id` | 运行元数据与子记录 |
| `GET /ai-runs/:id/events?after_id=0&limit=200` | 按递增事件 ID 分页，包含子记录事件 |
| `GET /ai-runs/stream?episode_id=1&after_id=123` | 剧集 SSE，`interaction` 事件携带 ID；重连优先使用 `Last-Event-ID` 补发 |
| `DELETE /ai-runs?episode_id=1` | 清理该剧集已结束的根记录及子记录 |
| `GET /ai-configs/codex/status` | 检查本机 CLI 与登录状态 |

已有执行接口补充 `run_id`；后台提取和批量提示词状态也携带对应记录 ID。图片、视频任务与自动提示词通过父子记录关联。事件独立序列化，不复用控制台截断日志。
